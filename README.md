# Buscador de Videojuegos

Aplicacion web interactiva para buscar y explorar videojuegos consumiendo la API de RAWG.

## Caracteristicas
- Buscador de videojuegos en tiempo real.
- Consumo de API mediante peticiones asincronas (fetch / async-await).
- Renderizado dinamico de tarjetas en el DOM con imagen, titulo y puntuacion.
- Estilos visuales adaptativos con CSS.

## Tecnologias
- HTML5
- CSS3
- JavaScript (ES6+)

## Uso
Abre el archivo proyecto.html en cualquier navegador web para ejecutar la aplicacion.
